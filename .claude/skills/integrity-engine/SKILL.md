Pipeline de selo automático: 1) Tem chave NF-e 44 dígitos + SEFAZ confirma + CNAE automotivo → OURO_SEFAZ. 2) SEFAZ rejeita → REJEITADO. 3) Foto sem QR + OCR ≥85% + CNPJ verificável → PRATA_OCR. 4) OCR <85% → PRATA_OCR + PENDENTE_CONFIRMACAO. 5) Sem comprovante → BRONZE_DECLARADO. Monotonia de odômetro: km novo deve ser ≥ último registro anterior e ≤ próximo registro posterior (ordenado por dataServico). Mesma lógica para horasMotor quando CAMINHAO. Trust Score: (ouro*1.0 + prata*0.7) / total * 100. Se zero registros, retorna null (não 0). Manutenções retroativas sempre permitidas com comprovante. dataServico e dataCadastro ambos visíveis no Dossiê.
